# Team Calculator — GitHub for Teams starter

The two files are intentionally simple for a collaborative Git/GitHub classroom lab.

- **Student A — `feature/ui`:** change `index.html` (heading, layout or styling).
- **Student B — `feature/logic`:** change `calculator.js` so the Calculate button performs the selected arithmetic operation and displays the result.
- Both students: make a meaningful commit, push the branch, open a pull request and review one another's changes.

To run: open `index.html` in a browser. No dependencies or server required.

This starter is optional. It is not the GitHub Classroom assignment repository. Use the repository and submission instructions supplied by your college when available.


# Team Calculator

A simple calculator built with HTML, CSS, and JavaScript as a two-person GitHub collaboration project.

## Features

- Addition, subtraction, multiplication, and division
- Support for negative numbers and decimals
- Error handling for empty or invalid inputs
- Error handling for division by zero
- Display results without reloading the page
- Responsive layout for different screen sizes

## How to Run

1. Clone or download this repository.
2. Open the `calculator_practice` folder.
3. Open `index.html` in a web browser.
4. Enter two numbers.
5. Select an arithmetic operation.
6. Click the Calculate button to see the result.

No installation or additional dependencies are required.
